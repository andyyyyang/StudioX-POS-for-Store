# 設計規則

StudioX POS 的畫面都照這幾條。新增或修改畫面前先看一遍。截圖在 `docs/screenshots/`（深色）與 `docs/screenshots/light/`（淺色）；提交訊息帶 `[screenshots]` 會重拍。

## 左邊選、右邊做

收銀台是站著、手忙的時候用的。眼睛一掃就要知道「下一步按哪裡」，答案永遠是同一個地方：**右邊那一欄**。

```
┌ 側欄 ┬ 工作區：看與選 ─────────────┬ 右欄：做 ───────────┐
│ 點餐 │ 頁首：標題（英文大字＋中文） │ 桌位            ×   │ ← 選起來的那一筆
│ 桌位 │ 切換（分段控制）              │ A2・4 位・32 分      │
│ …   │                              │ [換桌]   [併桌]      │ ← 它的動作（動作鍵）
│     │ 清單、卡片、桌位圖、單子        │ [印結帳單][作廢]     │
│     │ 點一下＝選起來                 │ 人數            ×   │ ← 要打數字時才出現
│     │ （卡片、清單上沒有按鈕）         │ 1   2   3           │
│     │                              │ …                   │ ← 鍵位永遠一樣、位置不動
│     │                              │ [       入座      ] │ ← 下一步（唯一的大橘鍵）
└─────┴──────────────────────────────┴─────────────────────┘
```

1. **工作區只負責看與選。** 清單、卡片、桌位圖、單子的每一行：點一下選起來，再點一下取消。卡片與清單上**不放按鈕**（狀態用顏色與標籤）。
2. **選起來的那一筆，動作都在右欄**（`.dockSelection(DockSelection(...))`，見 `StudioXPOS/Keypad/Dock.swift`）：
   - 最上面是它的卡片：種類（桌位、訂位、會員、這一行）、名字、一行說明、狀態標籤，右上「×」取消選取
   - 下面是**動作鍵**：兩欄、和數字鍵同一種鍵。危險的（作廢、退款、取消、刪除）自動排到最後、紅字，按了要確認或主管授權
   - **主要動作是鍵盤最下面那顆大鍵**：入座、結帳、好了、入場、開單。一整個畫面只有這一顆大的橘色鍵
3. **要打數字：右欄的鍵盤問**（`await keypad.ask(...)`）。題目與大字出現在數字鍵正上方；問完回到原本選起來的那一筆。不要用 sheet 或系統鍵盤打數字。
   - 問的時候，選起來的那一筆照樣留在上面（小卡：種類、名字、說明），面板裡的選擇要打數字時留一條面板的標題——一看就知道這個數字是給誰的
   - 數字鍵與大鍵永遠貼在最下面：上面那一塊（卡片、題目、快速鍵）怎麼變，鍵的位置都不動
4. **不用打數字的選擇蓋住右欄**（`.dockPanel`）：選桌子入座、選設計師、選規格、退款與換貨的選項、選付款以外的清單。左邊的內容保持完整；面板裡要打數字時面板讓開、鍵盤回來，打完面板再回來。面板裡的選項用 `DockChoice`。
5. **這一頁的動作**（新增訂位、新增會員、新增出單機）在沒選東西時出現在右欄（`DockSelection.page(...)`）：動作鍵在上面、大鍵在下面。頁首只放標題與切換，不放按鈕。
6. **切換用分段控制**（今天／這一班、進行中／全部、樓層），不要一排各自獨立的按鈕。
7. **同一個動作在同一個畫面只出現一次。**
8. **字不能被截斷。** 寬度不夠時減少一行裡的東西、換成兩行、或把次要資訊收起來；名字、金額、時間永遠完整。
9. **淺色與深色都要好看。** 顏色一律用 `Theme` 的色票（亮、暗各一個值），不要寫死 `.white`／`.black`（印出來的單據例外）。外觀預設跟著 iPad；截圖兩種都拍。

### 例外

- **單子欄**（點餐頁中間那一欄）本身就是「選起來的那一筆」：沒選某一行時，整張單的動作（送單、結帳、打折、拆單…）在右欄；點了某一行，右欄換成那一行的卡片與動作（備註、折扣・改價、指定設計師…），**鍵盤直接問它的數量**（`keepsSelection`：帶入現在的數量，打數字＝改、−1／+1 一按就改，大鍵「數量 2」／「改成 3」；0＝刪除），改好了接著問同一行，再點一下那一行＝不選了。
  - 單子上的一行可以滑：往左＝刪除（還沒送出的滑到底直接刪；送出去的只露出「作廢…」，要原因、要主管）；往右＝−1、+1（可以連按，滑到底＝+1）。
  - 刪掉還沒送出的**不留紀錄**（`lines.removed`，下面跳「已刪除 拿鐵・復原」）；送出去的照樣作廢（`lines.voided`：廚房印作廢單、報表算損耗），但單子上不再列出作廢的行。
  - 單子的頁首：標題（桌號／稱呼／單號）＋叫號的號碼、一行「阿珠・23:19」、用餐方式的分段控制（內用／外帶／外送；點一下就改，內用改外帶、外送而且在桌上的先問「A2 的桌子會空出來」；結帳中只看不改）。標題不再寫用餐方式。
  - 頁首右上的「選取」（單子欄唯一的字鈕）：一次勾好幾行——點一行＝勾／不勾（不能滑、不問數量），右欄換成「選取・已選 3 項」：大鍵是刪除（都還沒送出）或作廢…（有送出去的），動作鍵是整筆折扣、備註、拆成新單、送廚房；「完成」、×、換單＝不選了。
  - 點左邊的品項就會開一張預設的單：右欄不放「開外帶單」這種一樣的鍵；全外帶的店也不放「開內用單／開外送單」。點餐頁的右欄沒有其他資訊（品項在左邊、單子在中間）；待機時打了數字才出現「下一個品項 × 3」或「品號 4710…」。
- **付款**：左邊選付款方式，右邊打金額；完成結帳是右欄的大鍵。
- **鎖定、配對**：右欄就是 PIN／配對碼的鍵盤。
- **設定**：表單在工作區；儲存、測試列印、刪除這類動作在右欄。

### 手機（iPhone）：上面選、下面做

店員手上的點餐機用同一套規則，只是「右欄」換到下面（`Shell/PhoneShell.swift`，收的是同一個 `DockKey`）：

```
┌ 系統的時間列 ──────────────┐
│ 這一頁：清單、品項           │ ← 點一下＝選起來
│ ┌ 桌位             ×  ┐   │ ← 選起來的那一筆：下面一張卡（種類、名字、說明、狀態）
│ │ A2・4 位・32 分       │   │
│ │ [送到櫃台] [印結帳單]  │   │ ← 動作鍵：兩欄、和數字鍵同一種鍵
│ │ [        加點       ] │   │ ← 主要動作：最下面的大鍵
│ └──────────────────────┘   │
│ 點餐  桌位  訂單  叫號  更多  │ ← 分頁
└────────────────────────────┘
```

- 沒選東西時，這一頁的主要動作浮在分頁上面，其他的收進「⋯」
- 要打數字（`keypad.ask`）：鍵盤從下面升起（sheet，鍵位和 iPad 一樣），問完收起來；往下滑＝取消
- 不用打數字的選擇（`.dockPanel`）：一張 sheet；面板裡的選擇要打數字時同一張 sheet 換成鍵盤（淡入淡出），打完換回來
- 點餐頁最下面是單子那一條（`PhoneTicketBar`）：點一下、往上滑打開單子；**結帳、送單只在打開的單子裡**（看過單子才結帳，點餐頁沒有直接結帳的鍵）
- **按住那一條說話點餐**（`Voice/`）：按住開始聽（字一邊出來）、放開就交給 Apple 的模型（Foundation Models）整理成「品名・價錢／規格・幾份・備註」，對到菜單加進單子；還沒有單子時那一條也在（說了就開一張）。一段一段的：上一段還在整理就可以按住說下一段。沒說哪個價錢、要選口味、賣完的不加，寫在那一段的結果裡（不跳警告）；沒有 Apple Intelligence 的手機直接從整句話找品名與數量（`POSCore/VoiceOrderText`）
- 點餐頁的單子、加料與規格也是 sheet，裡面一樣是上面選、下面做；**不疊第二張 sheet**：這兩張裡的鍵盤與面板從這一張的下面升起來（`PhoneDockHost(inSheet: true)`），點暗下來的地方或把橫條往下拉＝取消
- sheet 一律 `.phoneSheetStyle(...)`：拖曳的橫條、圓角 22、單子與加料是暖紙色、鍵盤與面板是右欄色
- 手機照常顯示系統的時間列、避開瀏海與下面的橫條（iPad 才滿版）
- 新畫面先想 iPad；手機只在放不下時加一個小的版本（`horizontalSizeClass == .compact`），動作還是同一份

## 每一頁的骨架

```
┌ 頁首：標題（英文大字＋中文小字） ┐
│ 篩選／切換（分段控制）            │
│ 內容：清單或圖（點了選起來）      │
└──────────────────────────────────┘
```

## 文字

- 數字用等寬數字（`.monospacedDigit()`）；金額用 `MoneyText`
- 一行放不下時：先拿掉次要資訊，再縮小字（`minimumScaleFactor` 不低於 0.7），最後才換行
