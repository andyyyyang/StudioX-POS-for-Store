# 門市收款：銀行刷卡機（EDC）的收銀機連線（ECR 連線）

iPad 把金額送到**銀行的刷卡機**（EDC），客人在刷卡機上刷卡、插卡、感應（也可以是悠遊卡這類電子票證，或刷卡機掃客人的電子錢包付款碼），刷卡機把結果回給 iPad，自動記成一筆付款。錢由收單銀行直接撥給商店，不經聚合商。

- 每台 iPad 各自設定（設定存在這台，和出單機一樣），**預設關**：沒打開的照舊「刷完卡手動輸入末四碼」。
- 第一個做的是**聯卡中心（NCCC）「8N1 標準」電文、UDP 區網連線**。台新等銀行的格式不同，之後加（`ECRDriver`）。
- 手機不接刷卡機（只有 iPad）。

## 開通（每家店）

1. 跟收單銀行（或聯卡中心）簽特約，拿到 EDC。
2. **請銀行在刷卡機的 TMS 打開**：「收銀機連線」、電文版本「8N1 標準（400）」、**UDP 收銀機連線**（區網）。要經刷卡機收電子票證、電子錢包的，請銀行另外開這些服務（票證、錢包可能要各自簽約）。這幾個都是 TMS 下載的參數，店家自己改不了。
3. 刷卡機接店裡的網路（網路線或 Wi-Fi），請網管把它的 IP 固定（DHCP 保留）。
4. iPad：**設定 → 刷卡機** → 打開「用刷卡機收款」→ 選「聯卡中心 NCCC」→ 填刷卡機的 IP、連接埠（預設 **50002**）→ 右欄「**測試連線**」（送 98 Echo）。第一次連 iPad 會問「區域網路」權限，要允許（`NSLocalNetworkUsageDescription`）。
5. 選哪些經刷卡機：**信用卡**（預設開）、**電子票證**、**電子錢包**（LINE Pay、悠遊付、全支付；刷卡機也收 icash Pay、全盈+PAY、Pi 錢包，記成「其他」；街口不在聯卡中心的名單上，照舊手動）。
6. 「等客人刷卡最多」預設 90 秒（30–300）：超過還沒有結果就查刷卡機的上一筆。

## 怎麼用

| 動作 | 刷卡機做什麼 | POS 記什麼 |
|---|---|---|
| 結帳選「信用卡」（或電子票證、LINE Pay…），右側鍵盤打金額 →「送到刷卡機」 | 一般交易 `01`（付款工具 N／E／W） | 核准：一筆付款。`reference`＝「授權 123456・調閱 000123」（電子錢包沒有授權碼：放錢包的交易序號）、`cardLast4`、`terminal`（端末代號、商店代號、批次、調閱編號、授權碼、卡別、主機、刷卡機上的日期時間、電子錢包的訂單編號與交易序號） |
| 等的時候按「取消」 | 不會馬上斷線：請店員在刷卡機上按取消，等刷卡機回（最多 20 秒），沒回就查上一筆 | 客人剛好刷了：照收 |
| 結帳前「退回第 N 筆」、結帳後「退款」，原本是刷卡機收的 | 當天、整筆 → 取消 `30`（帶原調閱編號、原金額；客人不用再刷）；其他 → 退貨 `02`（帶原授權碼；客人要再刷原卡）。取消不行（刷卡機已經結帳換批）可以按「改用退貨」 | 刷卡機退好了才記（退款上的 `terminal`）；刷卡機壞了、或已經在刷卡機上自己退了 → 「只改 POS」 |
| 設定 → 刷卡機 → 右欄「查上一筆」 | `62`（上一筆是電子錢包時刷卡機回 `0010`，再送 `68`） | 顯示上一筆 |
| 設定 → 刷卡機 → 右欄「刷卡機結帳」（要能交班的人） | 結帳 `50`（日結、換下一批） | 顯示筆數、金額 |

退款單（印出來的）多一行「刷卡機：調閱…・授權…・批次…」。

## 不重複扣款

1. 交易**只送一次**。刷卡機回 NAK 才重送，而且用**同一個 16 碼標頭**（`POSTxUniqueNo`）——刷卡機認得是同一筆。
2. 回覆要對得上標頭才算這一筆的（前一筆遲到的回覆不會被當成這一筆）。
3. **等不到結果**（逾時、斷線、按了取消後刷卡機沒回、回覆壞了三次）→ **查上一筆**（`62`，上一筆是電子錢包再 `68`），最多 3 次：
   - 核准、交易別對、金額對、**不是已經記過的調閱編號**（同一台、同一批、同一個調閱編號）→ 就是這一筆，照記（畫面寫「查上一筆確認的」）；
   - 對不上 → 沒有扣款；
   - 連上一筆都查不到 → **不確定**：卡片上沒有「再試一次」，只有「再查一次」、「刷卡機上有成功：手動記一筆」、「沒有成功，關掉」。
4. 刷卡機核准了但這台存不進去（極少見，例如儲存空間壞了）→ 跳出金額與授權碼請店員記下來，**不要再刷一次**。
5. 刷卡機收或退的時候不會自動鎖定。

## 示範模式

示範店用**模擬的刷卡機**（`ECRSimulatedTerminal`，不連網路）：收到交易先回 ACK、兩秒後核准；查上一筆、電子錢包查詢、取消、退貨、結帳、連線測試都照電文回。設定 → 刷卡機 打開就是用它（不用 IP），截圖可以用啟動參數 `-cardTerminal`（不存設定）。示範按「取消」＝模擬店員在刷卡機上按取消。

## 電文：聯卡中心 8N1 標準（400 bytes、ASCII）

**卡別**：`01` U Card、`02` Visa、`03` Master、`04` JCB、`05` AMEX、`06` 銀聯、`07` Diners、`08` Smart Pay、`11` 悠遊卡、`12` 一卡通、`13` 愛金卡；電子錢包 `21` LINE Pay、`22` 悠遊付、`23` icash Pay、`24` 全盈+PAY、`25` 全支付、`26` Pi 錢包。

**金額**：新台幣沒有角分——不是整數元的金額不送（寧可擋下來）；最大 NT$9,999,999,999（12 碼）。

## 封包

- **RS-232**（或序列轉網路盒）：`STX 資料 ETX LRC`。LRC＝資料加 ETX 逐位元組 XOR（STX 不算）。收好回 `ACK ACK`、壞了回 `NAK NAK`，最多重送 3 次。資料裡的 0x00 當空白送。
- **UDP**（區網，刷卡機預設 50002）：`SOH＋16 碼標頭（POSTxUniqueNo）＋STX 資料 ETX LRC＋EOT`；LRC 一樣只算資料加 ETX。刷卡機原樣帶回標頭。POS 的標頭是台北時間 `yyMMddHHmmss`＋4 碼流水號。一框最多拆成 5 個 UDP 封包（POS 送的 421 bytes 一個封包就夠；收的時候照順序接回來，超過 5 個放棄）。
- POS 本機也綁 50002（刷卡機可能回到 POS 的同一個埠；綁不到就用系統給的）。

## 哪些是確認過的、哪些是推的

來源：聯卡中心端末程式（虹堡 V3 機型，`adsf0751/V3App` 的 `ECR.c`、`ECR.h`、`ECR_Define.h`、`ECR_Struct.h`、`RS232.c`，2026-03 仍在更新）。聯卡中心的正式規格書沒有公開。

| | 程度 |
|---|---|
| 400 bytes 的欄位位置與長度（端末拆收銀機電文的欄位表、組回覆的程式，兩邊一致） | 程式裡看得到 |
| 金額 `%010lu00`（10 位整數＋2 位小數）、文字左靠右補空白、數字右靠左補 0 | 程式裡看得到 |
| 交易別、主機代號、卡別、錢包業者代碼、付款工具 N／C／S／E／W／T | 程式裡看得到 |
| STX／ETX／LRC（STX 不算）、ACK／NAK 各送兩個、重送 3 次、0x00 當空白 | 程式裡看得到 |
| UDP：SOH＋16 碼標頭＋框＋EOT、LRC 不含 SOH／標頭／STX、刷卡機帶回標頭、預設 50002、最多 5 個封包 | 程式裡看得到（UDP 那段在原始碼裡被註解掉，但寫得出格式） |
| `0000`＝成功；查上一筆時上一筆是電子錢包回 `0010` | 程式裡看得到（另一份 POS 端 C# 也用 `0000` 判斷成功） |
| 電子錢包那一塊（訂單編號、載具、退貨訂單編號、交易序號）的位置 | 程式裡看得到 |
| 結帳回覆：有效期欄＝總筆數、金額欄＝總金額 | 程式裡看得到（結構的註解） |
| 每種交易收銀機要填哪些欄位（退貨帶原授權碼、取消帶原調閱編號＋原金額、分期期數放 175） | **推的**：退貨帶授權碼來自另一份 POS 端實作；取消核對原金額來自端末的錯誤碼「取消金額不符」 |
| 收銀機送的 Version Date 帶 `260116`、Trans Type Indicator 空白、查詢類不帶主機與付款工具 | **推的** |
| UDP 一框怎麼拆成多個封包、ACK／NAK 在 UDP 上是不是一樣兩個位元組（也接受包了標頭的）、刷卡機回到哪個埠 | **推的**（端末的 UDP 收送函式不在原始碼裡） |
| `0000`、`0010` 以外的回應碼是什麼意思 | **不知道**：畫面寫「沒有核准（代碼 XXXX）」 |

## 上線前要跟銀行／聯卡中心確認

1. 8N1 標準與 **UDP 收銀機連線**的正式規格書（NDA）；POS 廠商的驗收流程。
2. 收銀機送的 Version Date、Trans Type Indicator 要帶什麼；查詢類要不要帶 Host ID。
3. 退貨要帶哪些原交易欄位（授權碼？日期？RRN？）；取消要不要帶金額。
4. UDP：刷卡機回到哪個 IP／埠（來源埠、還是 TMS 設定的 POS 位址）；ACK／NAK 在 UDP 上怎麼送；什麼時候會拆成多個封包。
5. 回應碼表（`0001`…）——畫面要寫成店員看得懂的話。
6. 虹堡哪些機型支援 UDP；TMS 能不能一次開好收銀機連線與 UDP。
7. 電子票證、電子錢包經刷卡機收：要不要另外簽約、費率。
